# AIAgent_GenerateSalesPitch
Sales Manager Agent working in insurance company:     a. Generates 3 sample sales pitch emails using different LLMs    b. Selects the best email     c. Formats the email with Subject, body and content     d. Sends the email to End-Customer  e. Aspects Used include: Guardrails, Handoffs, Agent as a Tool, Function as a Tool, real-time email API
